# DSA Learning Agent

## Vision

DSA Learning Agent is an AI-powered personalized DSA learning platform.

The goal is to replace static sheets such as:

* Striver A2Z
* NeetCode 150
* Blind 75

with an adaptive learning system.

Instead of giving every student the same path, the platform should continuously learn from user performance and recommend the optimal next problem.

---

## Core Philosophy

The platform should answer:

"What should this specific student solve next?"

rather than:

"What comes next in a fixed sheet?"

---

## Main Components

### 1. Recommendation Engine

Uses:

* LinUCB
* Contextual Bandits
* User Skill Modeling

to recommend the next best problem.

---

### 2. Skill Matrix

Tracks mastery across:

* Arrays
* Strings
* Graphs
* Trees
* DP
* Greedy
* Heap
* Backtracking
* Binary Search
* Sliding Window
* Other DSA topics

---

### 3. Learning Analytics

Track:

* Solve accuracy
* Solve speed
* Contest performance
* Interview performance
* Revision requirements
* Weak topic identification

---

### 4. AI Mock Interview Studio

Provides:

* Timed interviews
* Socratic questioning
* Complexity discussions
* Communication evaluation
* Coding evaluation

---

## Success Criteria

A student should receive:

* Personalized recommendations
* Weakness detection
* Adaptive revision plans
* Interview preparation
* Contest preparation

from a single platform.
